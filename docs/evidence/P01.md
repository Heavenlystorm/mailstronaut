## Servo and distribution limits

`cargo info servo@0.7.0` in the Nix shell retrieved the published release metadata. Its default features include bundled resources, clipboard, JavaScript JIT and multiprocess; disabling JIT alone is not a script security policy. The release was not added to the graph or compiled. The source exposes both webview and Servo resource callbacks; their default implementations do not block loads. A safe renderer requires explicit response handling and verification of all schemes, not only these callbacks. No sanitized document API, resource isolation, CSP, input handling, native theme propagation, accessibility bridge or teardown exists yet. The wrapper has not been compiled against this graph, so its incompatibility is not claimed as proven by this spike.

A Nix shell provided Flatpak 1.18.4 and flatpak-builder 1.4.10; `flatpak --user list --runtime` returned no runtimes. No SDK, application build, sandbox capability, installed app or SpiderMonkey build was tested. No GUI, Wayland/X11, theme, privacy, memory, idle CPU, headless lifecycle, CI or live-mail acceptance is claimed. Keep all P01 checklist rows unchecked.
