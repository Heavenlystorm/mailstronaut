## Servo and distribution limits

Its default features include bundled resources, clipboard, JavaScript JIT and multiprocess; disabling JIT alone is not a script security policy. The release was not added to the graph or compiled. The source exposes both webview and Servo resource callbacks; their default implementations do not block loads. A safe renderer requires explicit response handling and verification of all schemes, not only these callbacks.
