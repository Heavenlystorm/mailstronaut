# P02 preliminary evidence (2026-10-27)

This is an incomplete feasibility spike, not P02 acceptance. Do not wire this
crate into application startup yet. `Config::validate` is preliminary: URL parsing,
provider consistency, reminder times, full cross-field rules, and user-facing field
errors require completion. OAuth URL prefix checks are not adequate security
validation. Evaluation must not run on the UI thread or on unbounded inputs in the
application: the same-binary helper, process limits, timeout and bounded IPC do not
exist yet. The crate currently exposes only the evaluator-side function.

The evaluator is pinned to Snix f393b22aa9b8e0e74c9e8d67f15454409299e510;
Serde is 1.0.228. `nix develop --command cargo test --workspace --locked --offline`
passed three synthetic tests: basic pure let/conditional and defaults, rejection
of unknown fields and `builtins.readFile`, and size/version rejection. This does
not prove all pure builtins, absence of all I/O, resource limits, or nontermination
handling. No mailbox, keyring, service, or personal credentials were accessed.

Strict Clippy with all workspace groups and `-D warnings` failed: the new crate
has numerous restriction lint findings and transitive duplicate package versions.
No lint groups were disabled. `nix flake check` initially failed because the Snix
Git source lacked a vendor hash; the fixed-output builder reported
`sha256-5vjUm3KUaciznlUYSKFhgjyzG1ZNTArKREA0OyPdu4Q=`. The full package gate
has not passed. CI, runtime/GUI, Home Manager linking, Flatpak and native secret
service acceptance have not been tested. No P02 PLAN rows are checked.

Remaining work includes a complete schema and redacted validation; secure URL
parsing; isolated limited helper and timeout/reaping; safe writes and managed
source detection; last-good reload; oo7 native/portal-backed credentials; tests
for all requested cases, evaluator memory/closure measurements, package and
strict Clippy gates, and disposable Home Manager linking. Never treat the current
partial API as a validated production configuration.

## Follow-up investigation

The follow-up is still incomplete and must not be wired into startup. The
unisolated evaluator is now private and compiled only for tests. Additional
preliminary validation uses `url` 2.5.8 and `chrono-tz` 0.10.4 for endpoint
and timezone checks, plus checks for reminder times, IDs, paths and bounds. The
chosen limits and provider rules still need review against the full contract;
validation and redaction are not complete acceptance evidence.

A synthetic standalone `{ kind = "password"; secretRef = "test"; }`
fails to deserialize as the internally tagged `Auth` enum through the pinned
Snix bridge with `missing field kind`. A regression test captures the current
failure, not successful account support. The documented account examples have
therefore not passed. Investigate the bridge/Serde interaction and implement a
compatible typed representation before relying on this schema.

The isolated helper, resource bounds, timeout, cancellation, typed IPC and
field-level error DTO remain unimplemented. Strict workspace Clippy still fails
with numerous restriction findings and transitive duplicate versions. No P02
checklist item is claimed by this investigation.
