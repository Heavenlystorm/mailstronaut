# P02 preliminary evidence (2026-10-27)

P02 remains incomplete. The evaluator is private, test-only, and unisolated; it
must not be wired into application startup. The same-binary helper, bounded IPC,
resource limits, timeout and cancellation/reaping are absent. No credentials,
managed writes, reload, Home Manager linking, or portal integration are implemented.

The pinned evaluator is Snix f393b22aa9b8e0e74c9e8d67f15454409299e510 and
Serde 1.0.228. Native Nix authentication now deserializes through a strict typed
intermediate map: the pinned Snix `deserialize_any` path formats strings with
quotes, preventing Serde's internal-tag visitor from recognizing `kind`. Typed
fields avoid that path; serialization retains the tagged schema. Synthetic tests
exercise the checked-in example, the documented Google, iCloud and manual accounts,
custom OAuth metadata, and rejection of hybrid, incomplete and unknown auth fields.
They also cover basic pure expressions, unknown keys, a readFile attempt, source
size/version, and preliminary URL and time validation. These tests do not establish
complete evaluator isolation, nontermination handling, security validation or live
account support.

Local `nix develop --command bash ci/check.sh` passed formatting, actionlint,
shellcheck, strict workspace Clippy and five configuration tests. The pinned Snix
vendor hash is `sha256-5vjUm3KUaciznlUYSKFhgjyzG1ZNTArKREA0OyPdu4Q=`. `nix flake check --no-update-lock-file --print-build-logs` and
`nix build --no-update-lock-file` passed locally on x86_64-linux; the flake
check omitted aarch64-linux. No P02 PLAN rows are
checked. CI, GUI/runtime, live authentication, native Secret Service, Home Manager
and Flatpak acceptance have not been tested. No real mail or secrets were used.
